# П17 — відповіді для звіту

1. **Чому на логарифмічній шкалі лінія `O(2^n)` пряма?**
   Логарифмічна шкала показує `log(y)`, а `log(2^n) = n · log 2` — лінійна функція від `n`, тому графік стає прямою з нахилом `log 2`.

2. **Чому дні простою не можна заповнити нулями?**
   Нуль означав би «сайт працював, але відвідувачів не було» — це неправда, і нулі штучно занизили б ковзне середнє; `NaN` чесно показує, що даних немає, і лінія розривається.

3. **Чим локатор поділок відрізняється від форматера?**
   Локатор вирішує, **де** стоять поділки (наприклад, кожні 2 тижні чи на початку кожного місяця), а форматер — **як** підписано значення в цих місцях (наприклад, `2.5%` або `1,200`).
